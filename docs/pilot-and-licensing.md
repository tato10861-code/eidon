# Eidon pilot and licensing proposal

## Sales principle

Sell an outcome, not an “AI employee” demo. Every engagement starts with a named workflow, an owner, a baseline, a target, the systems involved, approval boundaries, and a stop condition.

## Recommended pilot

**Duration:** 30–60 days. **Commercial shape:** $5,000–$15,000 fixed fee plus model/provider costs. **Scope:** one department, one primary employee profile, up to three approved integrations, one evaluation suite, and one weekly operating review.

**Acceptance metrics:** define three to five measurable targets before implementation. Examples include time-to-first-response, qualified cases completed, human escalation rate, factuality score on a fixed scenario set, cost per completed task, and percentage of actions requiring approval. Do not use illustrative dashboard data as customer evidence.

**Pilot deliverables:** configured employee profile, guarded tool path, evaluation scenarios, trace and usage report, export procedure, operator runbook, security questionnaire responses, and a written recommendation for hosted Scale, private deployment, or no-go.

## Hosted Scale

Start at $499/month with usage, model, retention, support, and integration limits made explicit in the order form. Add paid onboarding for custom workflows. Gross margin must be calculated from actual inference and support costs before promising discounts or usage commitments.

## Enterprise/private deployment

Price by deployment complexity, annual commitment, support scope, and integration burden. Separate platform license, implementation services, infrastructure/model costs, and support. State which capabilities are shipped, which are customer-configured, and which require roadmap work.

## OEM/license

Use a negotiated commercial license covering permitted deployment count, source availability, white-label rights, redistribution and sublicense rights, update cadence, security responsibilities, support, indemnity, data ownership, model/provider obligations, and termination/export. A public marketing page is not a substitute for the executed license.

## Qualification checklist

Before accepting a pilot, capture the buyer's workflow owner, data classification, required systems, authentication model, region, retention/deletion requirements, approval policy, procurement requirements, baseline KPI, target KPI, and decision date. Reject pilots that require unsupported SSO/SCIM, live provider execution, air-gapped deployment, or regulated data handling unless the contract explicitly treats them as engineering deliverables with acceptance tests.

## ROI worksheet

Estimate value using: `(baseline minutes − assisted minutes) × completed tasks × loaded hourly cost − model cost − support cost`. Use a range, show assumptions, and validate it with the buyer. Never present a forecast as realized savings or guaranteed profitability.
